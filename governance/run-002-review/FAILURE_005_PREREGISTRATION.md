# Recorded failure: N80A observation eligibility unspecified

Registry status: RECORDED under the 2026-09-09 Operator act; see FAILURES.md.

Frozen N80A defines the earliest threshold crossing of Q_k but does not operationally identify which rows in a heterogeneous cycle-summary stream are eligible observations of that quantity. The baseline Q0 is explicitly tied to reference capacity checks; that does not by itself supply a missing N80A row-selection rule. All 72 N80A records therefore remain underdetermined in this review, including zero-discharge and ordinary cycling triggers.

Prospective methodological lesson: preregistration should define the operational eligibility predicate and source-record binding for every measured quantity. It should also specify handling of implementation nonconformance in its disposition table. These are prospective lessons, not amendments to Sandia's frozen formulas or a new estimator for the observed data.

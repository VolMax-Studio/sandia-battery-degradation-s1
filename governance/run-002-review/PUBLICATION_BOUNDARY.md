# Public/private evidence boundary

The public project distributes frozen methods, source manifests/hashes, scripts and sanitized derived governance accounts. Private raw cycle/time-series CSVs, acquisition ZIPs, original email correspondence, private share URLs/identifiers, operator GO capture and private review bundles are excluded from this candidate.

This tree is based on the specified existing public base commit and contains only newly authored sanitized governance records. It does not descend through the private custody commits. Deleting private files from the tip of a branch that contains them in prior commits would not remove them from a push.

Standalone redistribution of source telemetry remains pending. Private-review restrictions apply to those review artifacts; they do not require making the public project private. The operator ratified administrative closure on 2026-09-09 and authorized publication only after a zero-finding publication-boundary audit. Private custody history must never be pushed.

# Representation instrument preparation v1

Governing RB0 v1.0.3 is ratified by the separate RB0_RATIFICATION record. This package contains a proposed rule specification, parameters, twelve-case reference manifest, source identities and a gate-record schema. It is PREPARED_FOR_OPERATOR_REVIEW, not an implemented or executed instrument.

## What is actually prepared

- THROUGHPUT_REPRESENTATION_MAPPING_V1.md: representation and throughput-only flow rules inside one gated instrument.
- REPRESENTATION_PARAMETERS.json: fixed inherited gate constraints and explicit nulls for unestablished source-bound parameters; no silent defaults.
- REFERENCE_CASE_MANIFEST_12.json: four slots per chemistry, including six concrete leading-window source anchors. Required protocol strata are candidate questions, not established labels. Six optional boundary/ambiguity locations remain MISSING_SOURCE_CASE.
- SOURCE_IDENTITY_INDEX.json: exact selected member/archive identities. No raw source rows, acquisition archives, private correspondence or local paths are included.
- DOCUMENTARY_SOURCE_PINS.json: pinned public protocol/schema sources and what their statements can and cannot establish.
- GATE_RECORD_SCHEMA.json: future record requirements; no reference or prediction records generated.

The selected cells are the first canonical cells in a metadata-only full-SOC / 0.5C-charge / non-0.5C-working-rate pool. Row windows 3–4 and 4–5 are anchored questions motivated by the documented three-check protocol; they are not claims that those positions actually satisfy the two mandatory strata. A general protocol statement cannot replace independent source-level adjudication. No capacity/current outcomes were inspected to select cases.

## Explicit remaining readiness limits

Flow reference coverage (NO_FLOW and CHARGE_DIRECTION_ONLY), optional source cases, exact protocol strata, source-bound coverage/reset/zero-resolution facts and qualified independent reference adjudication remain unestablished. Case gaps are not proof that candidates do not exist. The manifest records these limits so they cannot become fabricated observations. It is not ready for a representation-gate run. Completing or reassigning cases requires documented pre-prediction versioning under the ratified rules, with no outcome-dependent selection.

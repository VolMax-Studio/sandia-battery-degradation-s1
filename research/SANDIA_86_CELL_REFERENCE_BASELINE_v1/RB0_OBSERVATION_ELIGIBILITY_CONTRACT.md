## 1. Purpose and precedence

This prospective exploratory contract specifies what may count as an observation before any RB1–RB5 calculation. The corpus and A1-H forensic examples have already been viewed; this is not a new confirmatory preregistration. The operator has ratified A1-H administrative closure; this contract does not repair its engine, reinterpret its result, modify frozen §6/§7, resolve A2, or reproduce Figure 2a.

This contract supersedes the earlier *draft exploratory plan's* implicit first-three-arbitrary-rows and adjacent-CSV-row crossing semantics for future baseline work only. Reusing twelve algebraic combinations does not make these the executed A1-H specifications. Baseline variants must use distinct RB-prefixed identifiers and bind this contract hash. No source data or scientific results are generated by preparing the contract.

## 2. Observation identity and immutable source order

A source observation key is (source member SHA-256, one-based data-row position excluding the header); also retain the original Cycle_Index lexeme. Cycle_Index alone is never a primary key. Preserve duplicates and source order; do not sort, deduplicate, fill, smooth, clamp or repair. Timeseries corroboration must identify its member SHA, exact sample-row span and unambiguous association with the cycle row. Ambiguous repeated indices cannot be joined by index alone.

Each classification carries rule_id, role, eligibility, reason_codes and evidence locators. Source metadata must supply chemistry, nominal capacity, temperature label, SOC window, charge/discharge protocol and units. Metadata temperature is a protocol label, not measured cell temperature. Absent or ambiguous nominal capacity/units makes dependent quantities NOT_EVALUABLE; no chemistry-default fallback.

## 3. Value states and row-role states

All scientific numeric outputs are nullable. Required statuses distinguish:

| State | Meaning | Numeric representation |
|---|---|---|
| ELIGIBLE_OBSERVED | Required source observation and units are established | Finite value, possibly a justified true zero |
| INELIGIBLE_ROLE | Row is known to belong to another operation | null for role-dependent capacity metrics |
| ROLE_UNDETERMINED | Source evidence does not establish the operation | null, never silently skipped as a known negative |
| MISSING_CHANNEL | Required column absent | null |
| MISSING_VALUE | Column exists but value is blank/NA/nonfinite | null |
| INVALID_VALUE | Bad units, impossible sign, corrupted record or contradictory evidence | null |
| REPRESENTATION_UNRESOLVED | Increment/counter meaning or covered operation boundaries are not established | null for the affected throughput channel and its subsequent prefix |
| TRUE_ZERO | Source establishes a measured zero for the specific quantity | numeric 0 with explicit evidence |
| NOT_EVALUABLE | A necessary prerequisite is unavailable | null with propagated reason |
| NOT_REACHED_WITHIN_AVAILABLE_RECORD | Complete eligible observation sequence never reaches threshold | null crossing; separate endpoint/censoring fields |

Row roles are CAPACITY_CHECK, ORDINARY_CYCLING, CHARGE_ONLY, REST_NO_THROUGHPUT, PARTIAL_DIAGNOSTIC, INTERRUPTED_ANOMALOUS or UNKNOWN. These roles are distinct from value validity. A valid charge-only row may contribute charge throughput while being ineligible as a discharge-capacity observation. Numeric zero discharge alone does not identify a role, a failed battery or an interrupted experiment.

## 4. Capacity-observation eligibility predicate CAPACITY_CHECK_V1

A row may represent Q_k only when all required evidence is satisfied:

1. CAPACITY_CHECK_ROLE_MAPPING_V1 below establishes the row role either from an explicit source-provided label (route A) or a prospectively fixed deterministic mapping of source protocol observables (route B). Per-row source labels are not mandatory for route B. Both routes require source locators, completed full-SOC reference-check evidence, versioned mapping rules and the falsification gate before RB1. A source's general protocol description alone is insufficient to identify an individual row. Roles must be mapped without capacity-threshold outcomes.
2. The check is documented as 0–100% SOC at nominal 0.5C charge/discharge. Metadata nominal capacity and the source units are known. Where current corroboration is available, active charge and discharge plateaus must be consistent with 0.5 × nominal Ah in amperes. Current corroboration tolerance is fixed at ±5% for this contract version; its rationale and change control are recorded in RB0_PARAMETERS.json. The ±0.05 current criterion is a necessary corroborative condition inside Route B, but is not sufficient by itself to establish CAPACITY_CHECK. It is not an outcome-fitted rule. Rest/CV-tail samples are excluded from plateau tests using documented protocol phases, not capacity values. Min/max summary current alone cannot establish plateau, completion or full SOC.
3. Discharge capacity is a valid nonnegative measured quantity; the row has no interruption/partial/quality exclusion. Full SOC must not be inferred from one voltage extremum alone.
4. A reported zero is eligible capacity only if source evidence explicitly establishes a completed valid capacity measurement with zero capacity. A charge-only row, rest row, missing discharge operation or unavailable value cannot satisfy this requirement merely by storing 0. A genuinely measured zero requires a dedicated TRUE_ZERO_CAPACITY evidence record.

A known ordinary, charge-only, rest or partial/diagnostic row is INELIGIBLE_ROLE for Q_k. A row lacking the required mapping is ROLE_UNDETERMINED. If future RB1 cannot establish the mapping from the supplied source evidence, it must report that limitation and leave affected scientific metrics unavailable; it must not relax this contract to obtain results. Operational phase/role mapping and the version-bound tolerance require approval with RB0 before execution. No new source claims are asserted here.

### CAPACITY_CHECK_ROLE_MAPPING_V1 — deterministic role evidence

This is a mapping specification, not an implemented or validated classifier. Representation feasibility/falsification and its review must precede role-classifier construction. A completed versioned role rule/parameter artifact and the independent sample gate below are prerequisites to future RB1.

- **Route A — explicit source label:** accept a source-provided reference/check phase identity only when its documented semantics and row association establish the full-SOC completed operation. Resolve contradictions against observable phase evidence as UNKNOWN, never by trusting a label that conflicts with its record.
- **Route B — deterministic observable mapping:** an explicit RPT label is not required. Define Boolean/unknown tests for (a) unambiguous sample-to-row association and complete coverage; (b) documented charge → upper-bound completion → discharge → lower-bound completion sequence; (c) full protocol voltage/SOC endpoint coverage; (d) documented CC plateaus in both directions within the fixed 0.5C corroboration tolerance; and (e) absence of source-indicated interruption/partial-operation exclusions. All tests must be TRUE for CAPACITY_CHECK. A documented incompatible operation is INELIGIBLE_ROLE. Missing or ambiguous required evidence yields ROLE_UNDETERMINED.
- Before classifier execution, the protocol-specific mapping artifact must freeze phase segmentation, active-sample and plateau predicates, minimum coverage/sample requirements, endpoint/completion tests, nominal capacity and all tolerances, with evidence locators and units. Voltage or SOC endpoints come from documented protocol evidence, not observed capacity or desired feasibility. No unspecified predicate may be supplied at runtime; an unestablished parameter yields UNKNOWN. This contract does not invent absent protocol endpoints or claim the mapping is currently executable.
- Allowed inputs are source identity, protocol metadata, timeseries current/voltage/SOC where actually available, phase/completion/sequence and coverage evidence. Capacity magnitude, Q/Q0, threshold flags, EFC80, Figure 2a markers and derived feasibility counts are prohibited inputs or tuning targets. Current/voltage summaries alone cannot establish phase completion or full SOC. Existing capacity value validity checks remain a separate prerequisite to using an established role as Q_k.
- Freeze code, protocol mapping, parameters and the hand-reference sample before the first validation run. Role classification is a separate instrument subject to the mandatory gate; permission for this route is not permission to run it now.

## 5. Throughput eligibility predicate THROUGHPUT_V1

**Orthogonality invariant:** ROLE_UNDETERMINED prevents role-dependent use as Q_k but does not invalidate otherwise complete, finite, correctly unit-tagged throughput increments. Role uncertainty and throughput continuity are separate dimensions. Only the THROUGHPUT_V1 failure conditions below break the corresponding EFC prefix; capacity-role history requirements for first crossing do not add a throughput failure condition.

Throughput uses complete measured per-row increments, not only capacity-check rows. Each channel must be finite, correctly unit-tagged and nonnegative. Confirm from source schema that values are per-row increments rather than cumulative counters; otherwise NOT_EVALUABLE. Complete valid measured intervals can contribute their actual recorded throughput independently of whether any scientific row role has been established. An interrupted record contributes only if its measured increment is explicitly complete for the covered interval; otherwise continuity is broken.

A zero channel is TRUE_ZERO_THROUGHPUT only when the source evidence confirms no flow in that direction over a complete covered interval. Complete source protocol/timeseries evidence may establish a throughput-only flow state such as BIDIRECTIONAL_FLOW, CHARGE_DIRECTION_ONLY, NO_FLOW or FLOW_STATE_UNRESOLVED: directly evidenced NO_FLOW can justify zero in both channels, and complete CHARGE_DIRECTION_ONLY evidence can justify zero discharge alongside measured charge. These flow states serve only channel coverage and TRUE_ZERO_THROUGHPUT; they do not assign CAPACITY_CHECK, ORDINARY_CYCLING, REST_NO_THROUGHPUT, CHARGE_ONLY or any other scientific row role, cannot establish Q_k eligibility, and do not require the downstream role classifier. FLOW_STATE_UNRESOLVED never justifies a zero by itself; all existing representation, channel-validity and coverage requirements still apply. A zero sentinel or unclassified absence of operation is not enough. The exclusive throughput failure conditions are unestablished channel/units/nominal denominator or increment representation, incomplete/unknown coverage, missing/invalid increments, and unresolved overlapping or duplicate-record identity. Each breaks the relevant cumulative channel from that row onward (a missing denominator invalidates the entire basis). An unknown role alone is not on this list. Do not skip the gap, impute zero or resume a full-prefix value after it. Pre-gap values may be retained with their coverage endpoint. EFCA depends only on discharge continuity; EFCB depends on both channels.

### Increment representation and operation boundaries

Use reason code INCREMENT_REPRESENTATION_UNRESOLVED (value status REPRESENTATION_UNRESOLVED) when a row may contain cumulative counters, overlap with its neighbor, or an unestablished multi-operation interval. Use OPERATION_BOUNDARY_AGGREGATION_UNRESOLVED for the specific boundary/aggregation ambiguity. Store candidate evidence and reason independently of row role. A capacity value near twice its neighbor, including an initial-block transition, is a review trigger and does not by itself prove duplicate counting or invalid units.

A documented aggregate of multiple **non-overlapping, fully covered** operations is AGGREGATED_DISJOINT_INCREMENT and may contribute its measured throughput once. Such aggregation does not establish eligibility as a single capacity-check observation. If overlap/double counting is established, use OVERLAPPING_INCREMENT and invalidate the affected prefix. If representation remains unresolved, keep null and break the affected prefix; do not divide by two, subtract a neighbor, drop a row, or convert a counter into increments under this contract. Any later representation conversion requires its own reviewed, versioned rule.

The review-reported row-4 pattern is not independently measured or resolved in this revision. No historical EFC arithmetic conclusion or A1-H artifact is rewritten by adding this prospective representation check.

### THROUGHPUT_REPRESENTATION_MAPPING_V1 — separate decision instrument

Representation mapping is distinct from role classification. It assigns each covered source interval/channel one of PER_ROW_INCREMENT, AGGREGATED_DISJOINT_INCREMENT, OVERLAPPING_INCREMENT or REPRESENTATION_UNRESOLVED from documented schema, counter/reset semantics, protocol-operation boundaries and unambiguous source coverage. A missing reset/interval/overlap fact remains unresolved. A confirmed cumulative counter is not silently differenced under this contract; use REPRESENTATION_UNRESOLVED with the unsupported-counter reason and halt the dependent path pending a separately reviewed conversion rule.

PER_ROW_INCREMENT and AGGREGATED_DISJOINT_INCREMENT permit throughput use only when all other THROUGHPUT_V1 validity conditions hold; OVERLAPPING_INCREMENT and REPRESENTATION_UNRESOLVED break the affected channel prefix. Existing valid pre-gap values remain valid; do not describe a later break as invalidating the entire preceding record. Role labels do not establish representation, and the role-classifier gate does not validate this instrument.

Before RB1, this instrument requires its own frozen decision rules/parameters, independently adjudicated source-reference cases, predictions and falsification/validation record. See RB0_REPRESENTATION_GATE_DESIGN.md for the proposed bounded design: PASS_SCOPED requires, for every included chemistry, independently resolved and definitely agreeing initial-block-to-working transition and ordinary within-block cases, with zero definite disagreements among all resolved cases of that chemistry; an empty or wholly unresolved scope cannot pass. Its construction-versus-adjudication independence rule is the same as for the role classifier. No EFC, EFC80, threshold outcome or model-feasibility count may be calculated or used to select representation rules during this gate. If source evidence cannot establish representation, record the exact channel/interval scope as REPRESENTATION_UNRESOLVED and HALT the dependent EFC path rather than relaxing THROUGHPUT_V1.

Comparison uses unrounded values; display rounding occurs only after decisions. Binary64 is the proposed numeric representation; record it, never compare displayed rounded numbers. Threshold is exactly the implemented multiplication 0.8 × the selected unrounded Q0. All tolerances, including current corroboration, are named in the machine-readable contract and version-bound parameter artifact. There is no Figure 2a comparator or A1-H verdict in this baseline.

## 7.1 Mandatory classifier falsification gate before RB1

Order: RB0 approval → representation mapping freeze → bounded representation feasibility/falsification → review → role-classifier freeze + independent sample → classifier falsification → review → separate RB1-only GO. Role-classifier implementation/preparation must await the representation review; each execution stage still requires its explicit authorization. No EFC or EFC80 is computed during representation feasibility. RB2–RB5 are not bundled into RB1 permission. This revision neither implements the classifier nor selects, labels or evaluates source rows.

**Reference sample design:** fix 24 source-row observations, eight each from LFP, NCA and NMC, before classifier validation. An independent human/reference adjudicator must establish labels from source protocol and timeseries evidence without seeing classifier predictions or capacity-threshold outcomes. Include at least two independently established capacity-check positives and one ordinary working-rate negative per chemistry, and at least two distinct charge-only negatives from two distinct cells and two distinct rest/zero-throughput negatives from two distinct cells overall. Within each of those two negative classes, seek chemistry diversity where source-verified candidates exist; do not invent absent chemistry/class combinations. Distinctness is required within each class, not four different cells across the two classes. Record unavailable coverage explicitly as a limitation and apply the existing insufficient-sample rule; never replace cases based on predictions or outcomes. The remaining slots may cover transitions, interruptions, boundary aggregation and ambiguous rows. Select by protocol/role evidence rather than threshold capacity; among eligible candidates for each required stratum use canonical cell_id then source-row order. Record the sampling pool, selection rationale, prior corpus exposure and all exact source keys. The sample is purposive, not a random estimate of population accuracy. Earlier A1-H forensic examples may be identified as already exposed examples, never called an unseen holdout.

**Independence and locking:** any author, specifier or implementer of the classifier or its decision rules is disqualified from producing or adjudicating the sealed reference labels used to falsify that same instrument. This includes the agent authoring this specification. The reference adjudicator must be independent of instrument construction and blinded to predictions; absolute institutional independence is not claimed. The same disqualification applies separately to THROUGHPUT_REPRESENTATION_MAPPING_V1 and its reference labels. Labels, supporting locators and UNRESOLVED cases must be sealed before predictions are available, independently of classifier outputs. An agent-generated guess is not a hand-adjudicated reference. The operator must establish the qualified reference adjudicator for that later step. Preserve every selected row, including unresolved cases; no replacement after predictions. If required source coverage/strata cannot be established, report REFERENCE_SAMPLE_INSUFFICIENT and do not claim a passed gate.

**Required record and decision:** record each reference role/eligibility, predicted role/eligibility, evidence, agreement, disagreement or unresolved status; provide full counts without discarding abstentions. Any definite disagreement on a resolved reference is a finding and yields FAIL, not a tuning signal. An abstention on a required positive or required negative leaves that required stratum unresolved and the gate INCONCLUSIVE. PASS requires the stated chemistry/positive/negative coverage, no definite disagreements, and definite correct eligibility predictions for the required strata. Other unresolved rows remain explicitly reported and limit scope. PASS establishes only that this bounded falsification sample did not reject the instrument, not general accuracy or 86-cell feasibility.

Do not tune and rerun against the same sample to erase a failure. A proposed revised instrument requires a new version and separately approved validation design; retain and report all earlier predictions and findings. The current tolerance must not change in response to a feasibility count. No RB1 count may precede this gate and its review; no RB2–RB5 calculation may precede separate authorization.
